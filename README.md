# Spieletracker

Private Web-App (PWA) für unsere Spieleabende: Partien eintragen, Punkte und Sieger festhalten,
Spiele je Spielerzahl bewerten und vor dem Spieleabend gemeinsam aussuchen, was wir spielen.

- Läuft komplett im Browser und lässt sich auf dem Handy über „Zum Startbildschirm hinzufügen“ installieren.
- Partien, Punkte, Bewertungen und Spielernamen werden **nur lokal auf dem jeweiligen Gerät** gespeichert –
  nicht in diesem Repository.
- Optional: gemeinsame Gruppe über Firebase (siehe `FIREBASE-ANLEITUNG.md`).

Spiel-Cover stammen von Verlags- und Händlerseiten und dienen nur dazu, die eigenen Spiele im Regal wiederzuerkennen.
